# TrailBase

Set `TRAILBASE_URL` and optionally `TRAILBASE_COLLECTION`; configure a collection with the logical fields and indexed ID. The adapter uses Records HTTP operations; transaction/batch behavior must be verified against the deployment. Official references: https://trailbase.io/documentation/ and https://trailbase.io/documentation/api/. Accessed 2026-08-28. SQLite direct mode is out of scope.
