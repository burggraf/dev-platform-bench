# Appwrite

Set `APPWRITE_ENDPOINT`, `APPWRITE_PROJECT`, `APPWRITE_KEY`, database and collection variables. Create a collection with an indexed document ID and benchmark fields. The adapter targets Appwrite Databases REST endpoints; batch semantics are provider/API dependent and must be smoke-tested before measurement. Official references: https://appwrite.io/docs/products/databases and https://appwrite.io/docs/references/cloud/server-nodejs/databases. Accessed 2026-08-28. Use one-record smoke only; never assume undocumented quotas.
