# Neon

API mode requires `NEON_DATA_API_URL` and `NEON_API_KEY`; direct mode uses a PostgreSQL `DATABASE_URL` through the shared `pg` adapter. Create benchmark-owned table/index and clean by run ID. Official references: https://neon.tech/docs/data-api/get-started and https://neon.tech/docs/connect/connect-from-any-app. Accessed 2026-08-28. API and direct measurements are not interchangeable.
