# Results

`results/result.json` is canonical and `results/summary.md` is review-friendly; both are ignored by Git. Results should include provider, transport, run ID, operation, payload/batch settings, attempted/successful/failed requests, rates, p50/p95/p99 latency, throttling/errors, and stability. Publish only sanitized files with endpoint hosts—not URLs containing credentials or connection strings—and disclose date, Node version, provider tier/region, runner location, schema, dataset size, and stage settings.
